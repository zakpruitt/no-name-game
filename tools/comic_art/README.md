# Comic art scripts

The Blender scripts behind `assets/comic/`. Everything in the comic style is generated by these:
characters, animations, dungeon pieces and the ability reels.

**This folder is a snapshot.** The live copy is `vendor_src/shaman_redesign/comic_poc` (with
`style_poc` beside it). `vendor_src/` is gitignored, so without this copy the art couldn't be
rebuilt from the repo. The scripts hardcode that `vendor_src` path, so copy them back there to run
them. Renders, `.blend` outputs and GLBs aren't stored here; they total about 1.9 GB.

| File | Makes |
|---|---|
| `comic_lib.py`, `comic_rig.py` | The look (toon, ink, halftone) and the enemy rig kit |
| `build_comic.py`, `rig_comic.py`, `abilities.py` | The shaman, his rig and his 12 hand-keyed moves |
| `export_comic_shaman.py` | `shaman_comic.glb` |
| `enemy_*.py` | One enemy each. `enemy_minion.py` is the template; `enemy_dummy.py` is the training punching bag |
| `chibi_pass.py` | Chibi proportions on a finished enemy blend: `blender -b out/enemies/<name>.blend -P chibi_pass.py -- <name>` -> `out/enemies_chibi/` |
| `chunk_pass.py` | After chibi_pass: thin bone parts unioned into a few masses per limb group, wider run strides, hit squint: `blender -b out/enemies_chibi/<name>.blend -P chunk_pass.py -- <name>` -> `out/enemies_chunky/` |
| `env_kit.py`, `env_room.py` | The 25 dungeon pieces and a composed room |
| `env_brazier.py`, `env_hook.py`, `env_pool.py`, `env_ledge.py`, `env_extra.py` | The four pieces with no KayKit twin (brazier lit / spilled, hook and chain, pool, ledge), on env_kit without editing it. These run from the repo (`blender -b -P tools/comic_art/env_pool.py`) and read the kit from the integration checkout's `vendor_src`; outputs go to this worktree's `vendor_src/env_art/out/` (gitignored, `ENV_ART_OUT` overrides) |
| `comic_vfx.py`, `ability_vfx.py`, `render_abilities.py`, `reel_room.py` | The comic effects and showcase reels. Blender only; not in the game |
| `style_poc/` | What the kit builds on: `build_poc.py`, `rig_poc.py` and `shaman_poc.blend`, which holds the baked retargets |

Run with Blender 5.2, headless, from `comic_poc`:

```
blender -b -P enemy_minion.py
blender -b ../style_poc/shaman_poc.blend --scene POC -P export_comic_shaman.py
blender -b ../style_poc/shaman_poc.blend --scene POC -P render_abilities.py -- room=1 hitsheet=1 out=name
```

Then bring GLBs into the game with `python tools/comic_glb.py`. See `docs/features/comic-style.md`.

`comic_vfx.py` uses the Impact font for its reels. That's for local renders only and isn't licensed
to ship; the game uses Bangers (`assets/fonts/`).
