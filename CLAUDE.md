# Awaken

Fast-paced 3D combo hack and slash. Godot 4.7, GDScript. Original characters only (no licensed IP in the repo).

For now the game is just the heretic's combat in a training room (ROADMAP round 28): no run, rooms, rewards or title screen. It boots straight into training.

## Design pillars
1. **Combat feel first.** Light / right-click strings, dash cancels out of anything,
   hitstop + shake + knockback + flash on every hit. Tune before adding content.
2. **Combos are the game.** Every string has a name, a guide row and (for the enders) a timed breaker;
   the weapon a light forms decides what the tentacle's right click does.
3. **Awakening.** Style rank (variety > mashing) fills the meter; activating it powers the hero up
   (damage, armour, gold rim, charged axe) with a cinematic burst.
4. **Chibi but badass** (`docs/features/art-direction.md`), in the comic style.

## Layout
- `scripts/game.gd` — autoload `Game`: hitstop, shake, combo/style rank, Awakening meter, input map (bound in code). Hitstop has a shape (`HITSTOP_EASE`/`SLOWMO_EASE` eased tail, `HITSTOP_OPENER` snappier first hit, breaker focus flat, overlapping stops each keep theirs: `_stops`, `_update_hitstop()`), raises `hit_weight` (the weapon trail swells with it) and fires the comic impact frame (`scripts/impact_frame.gd`, `Game.impact`: a screen-reading CanvasLayer under the HUD, big stops and kills, `reduce_flashing` keeps only a vignette pulse). Checks: `tests/hitstop_check.gd`, `tests/impact_frame_check.gd` (PASS/FAIL); look: `godot --path . -s tests/impact_preview.gd` → `user://impact_preview.png`. See `docs/features/impact-feedback.md`
- `scripts/player.gd` — the heretic's state machine. Moves live in `MOVES` (timings are fractions of anim length); `COMBOS` names the combos (name, input, tier): landing one plays `combo_<tier>` and shows the name above him. `void_route()` is the only routing function (`_routed()` adds the frost-spear vault; `_next_move()`, the combo guide and the checks all use it). Hops / air moves / air dash / plunge and the breaker leap: see `docs/features/combo-breakers.md`. `_cast()` fires the spirit casts (`elements.CASTS`: echo on L1 / L2, tomahawk on DL; `docs/features/spirit-casts.md`). The hero's own element is spirit (`element()`); each void move takes its element from the weapon (`VOID_ELEMENT.ELEMENT_OF`); Awakened is gold (`AWAKEN_COLOR`)
- `scripts/move_list.gd` — every input grouped for reading (`SECTIONS`: weapons, storm, ice, magma, dark), drawn by the pause menu's MOVES panel. Add a row with each new move; `godot --headless --path . -s tests/move_list_check.gd` walks each row through `player.void_route()` and fails on anything unlisted, unreachable-but-unlisted or wrong (PASS/FAIL)
- `scripts/void_grab.gd` + `void_arm.gd` + `void_tendril.gd` — the tentacle: right-click grab and slam, R swing, breaker holds, and the arm's weapon shapes (`ComicLook.HERO_FORMS`; rests as a free hand). Check: `tests/void_arm_check.gd`. See `docs/features/void-arm.md`
- `scripts/void_element.gd` — right click: L picks the weapon and its element, right click has the tentacle do that element's thing (`AFTER`, `LIGHT_AFTER`, `fire()`), and the enders' breakers (`BREAKERS`, `entry()`, `breaker_impact()`). `scripts/thrown_foe.gd` sends foes flying (ice cubes, shoves, reels), `scripts/floor_bind.gd` holds them with tendrils out of the floor, `scripts/frost_spear.gd` is the planted spear that sets up the ice breaker, `scripts/dark_fx.gd` is the dark element (right click with no weapon first). Its lava wells, arcs and geysers are in `scripts/elements.gd`; `scripts/foes.gd` is `FOES.near()` (living foes in a radius). Look: `tests/element_shots.gd`. See `docs/features/void-element.md`
- `scripts/breaker_cue.gd` (floor timing rings), `breaker_prompt.gd` (the timing circle by the hero, reads `player.breaker_window()`), `breaker_quake.gd` (war cry, crater). See `docs/features/combo-breakers.md`
- `scripts/combo_guide.gd` — the next-input rows beside the hero mid-string: reads `player.combo_options()` and `combo_window()` every frame; toggle `Game.combo_guide` (Settings). See `docs/features/combo-guide.md`
- `scripts/main.gd` — the training room: builds the arena from KayKit / comic dungeon pieces (four pillars R can swing on), spawns the hero, camera, HUD and the dummies, and runs the autotest bot (`BOT_STRINGS`). `_spawn()` / `_spawn_boss()` still exist for tests; nothing spawns foes in play
- `scripts/training_dummy.gd` — the dummies: never fight back or die, walk home, refill, punching-bag wobble. The pause menu (`scripts/pause_menu.gd`) has Fill Awakening, Settings, Restart training. Check: `tests/training_check.gd`. See `docs/features/training.md`
- `scripts/enemy.gd` — skeleton AI: spawn → chase → telegraphed windup → strike; poise, launch/juggle. Hit reactions all live in `_hit_reaction` (called once in `take_hit` beside the sparks): `SQUASH` per kind, lean along the knockback, `Fx.flash_tint` in the hero's colour, kill hold, and crowd hits in one frame react `WAVE_STEP` apart; juggles hang at the apex (`_gravity`, `launch_speed_for`), tumble, bounce and skid; direction counts (`launch < 0` or `knockback.y < 0`, or a fall past `SPIKE_FALL`, craters; side launches roll; big hits swell the foe's own outline, `Fx.outline_own`). Check: `godot --headless --path . -s tests/enemy_feel_check.gd` (PASS/FAIL, prints the arc numbers); look: `godot --path . -s tests/enemy_feel_preview.gd` → `user://enemy_feel.png`. See `docs/features/enemy-hit-reactions.md`
- `scripts/enemy_types.gd` — foe data (`TYPES`, `BOSS`; `main.ENEMY_TYPES` / `BOSS_SPEC`), kept for later rounds; `scripts/boss.gd` (Bone Warden, `ATTACKS`), `bone_spike.gd`, `bone_cage.gd`, `projectile.gd` (enemy bolts; i-frames pass through, perfect dodge still triggers)
- `scripts/hud.gd` (+ `enemy_bars.gd` health bars, `threat_arrows.gd`), `scripts/camera_rig.gd`, `scripts/fx.gd` (damage numbers, sparks, rings, flash; textured sprites from `assets/vfx/` via `Fx.TEX`: `burst(..., tex, add)` particles, `flare()` camera-facing pops, `particle_mat()` shared by elements.gd; `swoosh()` = each melee hit's arc out to the move's `range`/`arc` (shaders/swoosh.gdshader, called from `player._swoosh()`, colour = the weapon trail's: the move's element, gold when Awakened). `weapon_trail.gd` + shaders/weapon_trail.gdshader = the ribbon on the axe. Kills: `death()` (gold flash + shock ring + `shards()` = shaded low-poly debris + smoke) from `enemy._die()`, `soul()` wisp as the corpse sinks. Combo feel: `chain_spark()` (from `enemy.take_hit`) adds hit flourishes in the hero's colour as `Game.combo_count` passes `Fx.CHAIN_TIERS` (10/20/35: star, spark spray, ring); `combo_pop()` bursts at the hero when a named combo lands (`player._combo_callout`), scaled by tier. Enders also get extra hitstop and a camera push-in per tier (`player.ENDER_HITSTOP`/`ENDER_ZOOM`, `_camera_hit`), and big hits/enders a directional nudge (`camera_rig.kick()`, scaled by the shake setting). Combo enders and chains past the 2nd tier add a second, wider, hotter swoosh (`player._swoosh`). Style rank climbs burst at the hero in the HUD's rank colour (`player._on_combo_changed`, camera push from S up). A fight's final kill gets slow motion + camera push-in + gold rings (`player._last_kill`, `LAST_KILL_SLOWMO`; autotest prints `[autotest] last_kill #N`). Every melee hit also throws debris in the hit's element (`Fx.element_hit()`: spirit wisps, wind streaks, obsidian chips + embers, ice shards + frost). `scorch()` = floor burn decal (flashes the colour, cools to soot): magma and breaker landings. Dash: `dash_streak()` floor smear + afterimages in `player._fx_color()` (element, or gold when Awakened); perfect dodge adds a big blue flare, rings and sparks. Awakening activation: `awaken_burst()` (faceted light `beam()` + flash + double shockwave + motes) in `player.try_awaken()` with a camera punch. Wind pillars are `elements.funnel()` cones with `swirl_mat()` (shaders/swirl.gdshader: spiral bands; saturated body via from_hsv since darkening pale colours goes grey); the same shader (low twist) makes the water geyser jet and (tight spiral) the spirit beam's shell. Prewarm (`elements.prewarm`) must draw new effect materials at real size under its 5% root; sub-pixel draws may skip the compile. Additive only for small hot cores: big additive shapes wash out on the light floor; pale flares need saturation to read). Camera hit feel (`camera_rig.hit_zoom()` per hit from `Game.register_hit`, more per chain tier, capped; `roll()` on heavy shakes from `Game.shake`; kicks/zoom/roll chase targets so stacked hits blend): `tests/camera_feel_check.gd`. The trail swells with the chain tier and `Game.hit_weight` (`weapon_trail.swell()`, `CHAIN_GROW`/`HIT_GROW`/`LIFE_GROW`, shader `UV2.x`): `tests/trail_check.gd`, look `tests/trail_preview.gd -- --swell`
- `scripts/elements.gd` — the element palette (`LOOK`), `CASTS`, the shared effect builders (bolt, pillar, fissure, nova, spikes, funnel / `swirl_mat`, `storm_strike`, lightning `arc`, `geyser`, the lava `Well`), the orbiting motes (`Orbit`) and `prewarm()`, which draws every material once at load (first-use shader hitches; new effect materials must be drawn there at real size). `comic_bolt.gd`, `comic_gale.gd`, `comic_geyser.gd`, `heretic_form_fx.gd` are the flat inked versions
- `scripts/comic_look.gd` + `scripts/comic_fx.gd` — the comic art style (always on; `Game.comic_style` is the flag the art code reads): `assets/comic/<kind>.glb` models and `assets/comic/dungeon/` pieces falling back to KayKit per piece, `shaders/comic_toon.gdshader` / `comic_emit.gdshader`, thicker `Fx.outline`, hard indigo lighting, onomatopoeia on hits. The hero plays his `Ab_` clips (`ComicLook.HERO_MOVES` retimes L1, L2, L3, DL, AL1); his stances are `player._comic_stand`, the axe's element is `scripts/comic_axe_aura.gd` (`ComicLook.infuse_axes`) and `comic_drag_mark.gd` the line it leaves on the floor. Look check: `tests/comic_shots.gd`. Blender sources: `tools/comic_art/` (a snapshot; `.gdignore`d). See `docs/features/comic-style.md`
- `scripts/heretic_rig.gd` + `scripts/heretic_form_fx.gd` + `assets/comic/heretic.glb` — the hero (Meshy model, the only hero): tentacle sway, the limb changing into each weapon with an inked burst, skirt spring bones. The default model is the chibi heretic (`assets/comic/heretic_chibi.glb`, `Game.HERO_DEFAULT`); `--hero=heretic` or Settings "Hero model" plays round 28's `heretic.glb` (`Game.hero_model`, `ComicLook.HERETIC_MODELS`). The chibi's signature clips are hand-keyed by `tools/meshy_rig/chibi_keys.py` (re-key, export, `contact_frames.gd`, then `heretic_shots.gd -- --clips` to film every clip from the game camera); `heretic_rig.gd` follows keyed claws and arms (`keyed`, `KEYED_ARM`). Rebuild: `tools/meshy_rig/`. Check: `tests/heretic_shots.gd`. See `docs/features/heretic-hero.md`. Making more models this way: `docs/features/meshy-pipeline.md` and the `meshy-asset-pipeline` skill
- **Art direction:** `docs/features/art-direction.md` — "chibi but badass": big head and hands, short body, oversized weapons, bold flat colour regions, menace from the silhouette (hood, tentacle, glowing eyes), never more detailed or serious. Read it before any model, Meshy prompt or texture decision
- `assets/kaykit/` — CC0 models (see CREDITS.md); `characters/Barbarian.glb` stays for the spirit casts' axe (`player.AXE_SOURCE`). `vendor_src/` holds the full packs; it's gitignored and `.gdignore`d — copy pieces into `assets/` to use them. `assets/comic/shaman_comic.glb` isn't loaded by the game: it's the clip source for `tools/meshy_rig/heretic_bake.py`
- `assets/sfx/` — synthesized placeholder sounds; regenerate with `python tools/gen_sfx.py`, play with `Game.sfx("name")`
- `assets/music/` — synthesized ambient + combat loops; regenerate with `python tools/gen_music.py`. `Game` plays them in sync and fades the combat layer by style rank (`MUSIC_RANK_LEVEL`)

## Workflow
- **Several agents at once:** each agent works in its own git worktree and branch (`bash tools/agent.sh new <name>` → `../awaken-<name>`, branch `agent/<name>`), commits there, and lands with `bash tools/agent.sh land` (rebase onto dev, resolve your own conflicts, headless checks, fast-forward dev). Never stage or commit in another agent's checkout, including `awaken/`. Rules: `docs/agents.md`
- VS Code: `.vscode/` recommends godot-tools (keep the Godot editor open for its language server and debugger), has launch configs (Play (training room), windowed Autotest, Current scene) and tasks for the headless checks (`Checks: all` is the default test task, `Check: one test` picks one)
- All checks: `bash tools/agent.sh check` (the PASS/FAIL tests in its list, then the autotest; `--quick` skips the tests). Tests: `void_arm_check`, `guide_check`, `training_check`, `prompt_follow_check`, `move_list_check`, `comic_check`, `hitstop_check`, `camera_feel_check`, `impact_frame_check`, `trail_check`, `rhythm_check` (run one: `godot --headless --path . -s tests/<name>.gd`); also `tests/enemy_feel_check.gd`
- Autotest (compile + a bot playing its void strings on the dummies, every breaker, about 16 s): `godot --headless --path . -- --autotest`. Prints `[autotest] combo_breaker #N <id> perfect=` per breaker and ends with `[autotest] done ... casts= breakers= perfect_breakers= moves=`, plus `[training]` and `[perf]` lines. `--start-awakened` starts with a full meter, `--reduce-flashing` turns that setting on without saving
- Visual check (windowed; screenshots to `%APPDATA%/Godot/app_userdata/Awaken/autotest_*.png`: `autotest_hit.png` ~0.2 s after the first big hit, `autotest_dash.png`, `autotest_guide.png`, `autotest_cast.png`): `godot --path . -- --autotest`. Measure perf windowed, not headless
- Looks (windowed, to `user://`): `tests/element_shots.gd` (every void move and breaker, `-- --only=maw` for one), `tests/heretic_shots.gd` (his rig and weapon changes; PASS/FAIL headless), `tests/comic_shots.gd` / `comic_preview.gd`, `tests/fx_preview.gd [-- --at=0.06 | --swoosh | --death | --dash | --awaken | --shots]`, `tests/trail_preview.gd [-- --swell]`, `tests/impact_preview.gd`, `tests/enemy_feel_preview.gd [-- --bag]`, `tests/breaker_prompt_preview.gd`, `tests/telegraph_preview.gd`, `tests/occlusion_check.gd`, `tests/enemy_lineup.gd`. `user://` is shared by every worktree: copy screenshots out right away
- After adding assets **or a new `class_name`**: `godot --headless --import --path .` (registers global classes)
- Skills in `.claude/skills/`: `roadmap-item` (one change end to end: build, verify, ROADMAP, commit), `combo-feel` (strings that move: MOVES / hops / routing), `combo-breaker` (timed finishers on enders), `spirit-cast` (shaped spectral spells)
- **Engine API reference:** `docs/engine_api/<ClassName>.xml` is the class reference for the exact Godot in use (`VERSION`; also `@GDScript.xml`, `@GlobalScope.xml`). Before using an engine method, property, signal or enum you aren't certain of in 4.7, grep it there (e.g. `method name="look_at"` in `Node3D.xml`, or search all files for a name) rather than recalling it. Regenerate after upgrading Godot: `python tools/gen_engine_api.py`
- **Feature docs:** `docs/features/` has a technical write-up per feature (how it works, files, invariants, tuning, tests); see its README for the index and the template. Read the relevant one before changing a feature, and add or update one in the same commit when you build or change a feature
- Scenes are mostly built in code; keep `.tscn` files minimal unless the user wants editor-authored scenes.
- KayKit models face +Z; facing yaw = `atan2(dir.x, dir.z)`. Characters share one rig, so any KayKit animation works on any character.
- Comic style: copy enemy GLBs with `python tools/comic_glb.py [src] [names]` (a plain copy loses the `g` attribute) and dungeon pieces with `--env`, then `--import`. Check: `godot --headless --path . -s tests/comic_check.gd` (PASS/FAIL: clips after mapping, tones, dungeon set, fallback, text logic, the hero's Ab_ retiming)
- Training flags (`docs/features/training.md`): `--spar=minion|rogue|shield|warrior` adds one live foe at 1/3 damage (`scripts/spar.gd`; the autotest prints `[spar] type= hits_taken= kills=`); `--bag-damping=N`, `--bag-stiffness=N`, `--bag-lean=N`, `--bag-squash=N` hand-tune the dummies' punching-bag spring live (`training_dummy.bag_overrides`). Each dummy shows a `LAST n` tag of its last string's damage. Element slams that crater (Deep Freeze, Meteor Fall, Maw) pass `Vector3.DOWN * *_DOWN` as knockback; the Warden reacts with `boss._boss_reaction` (flash, and ink + small squash on big hits)
