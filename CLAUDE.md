# Awaken

Fast-paced 3D combo roguelike hack and slash. Godot 4.7, GDScript. Original
characters only (no licensed IP in the repo).

## Design pillars
1. **Combat feel first.** Light/heavy strings, dash cancels out of anything,
   hitstop + shake + knockback + flash on every hit. Tune before adding content.
2. **Awakening.** Style rank (variety > mashing) fills the meter; activating
   transforms the hero (moveset/speed/damage, super armor, cinematic burst).
3. **Combo-slot upgrades (roguelike hook, not built yet).** Run rewards attach
   to specific moves ("3rd light hit releases a fire wave"), so each run builds
   a different combo string.
4. Tower defense is parked. If it returns, it's a room type, not a mode.

## Layout
- `scripts/game.gd` — autoload `Game`: hitstop, shake, combo/style rank, Awakening meter, input map (bound in code)
- `scripts/player.gd` — hero state machine; moves live in the `MOVES` table (timings are fractions of anim length); `COMBOS` names the combos (name, input, tier): landing one plays `combo_<tier>` and shows the name above the hero, and the pause menu lists them as MOVES
- `scripts/enemy.gd` — skeleton AI: spawn → chase → telegraphed windup → strike; poise, launch/juggle
- `scripts/main.gd` — builds arena from KayKit pieces, run of rooms (`RUN_LENGTH`, `path_options()`, `ENEMY_TYPES`, `wave_composition()` are the tuning data), autotest bot
- `scripts/upgrades.gd` — combo-slot upgrade data (`Upgrades.ALL`, per-level numbers in each `lv`); effects are implemented in `player.gd` by id; `Upgrades.SYNERGIES` boosts tagged powers once two are owned (applied in `player.upg()`). `reward_screen.gd` offers 3 between rooms; `run_summary.gd` ends the run
- Power paths: each power has a `path` (`Upgrades.PATHS`: light/heavy/dash/awaken/soul, colour + key + mastery numbers); fusions add a second `fusion` path and are only offered once both are owned. Icons: `python tools/gen_power_icons.py` → `assets/icons/powers/<id>.svg` (then `--import`), drawn by `scripts/power_icon.gd` (`PowerIcon`). Check: `godot --path . -s tests/power_check.gd` (PASS/FAIL, headless works; windowed renders `user://power_cards.png`, `power_build.png`, `power_hud.png`). See `docs/features/powers.md`
- `scripts/run_map.gd` — `RunMap`: the run's map, generated once per run from `main.run_rng` (`LANES`, `WEIGHTS`, `KINDS`, `TRIALS` are the tuning data; no two fightless rooms linked, a rest before the boss); `map_screen.gd` draws it and takes the pick between rooms (pause menu → Map shows it read-only). Vaults (`main._vault`, `vault_prop.gd`) offer 3 powers of one path; trials are smaller fights with a condition that pays a fusion (`Upgrades.roll_fusion`). Check: `godot --headless --path . -s tests/map_check.gd` (500 seeds, PASS/FAIL; windowed renders `user://map_check.png`); autotest saves `autotest_map.png`. See `docs/features/run-map.md`
- `scripts/training_dummy.gd` — Training (title → Training, `--training`): one room, a dummy that never fights back or dies (walks home, refills); the HUD shows each string's damage; the pause menu swaps to free power picks / Fill Awakening / Ascend / Restart training (`main._start_training`, `pause_menu._open_training`). Check: `godot --headless --path . -s tests/training_check.gd` (PASS/FAIL). See `docs/features/training.md`
- `scripts/ascendancy.gd` — `Ascendancy.PATHS` (wind/earth/water): picked at hero level 6 (`Game.LEVEL_XP`, XP = enemy bones) on `ascend_menu.gd`; reshapes Awakening (colour, passive, finisher replacing Cataclysm). Effects (lightning, Tempest, magma, Volcano, chill/freeze, Glacier) live here; enemies get `chill()`/`freeze()`
- `scripts/elements.gd` — the shaman's elements (spirit before an Ascendancy, then wind/earth/water): `CASTS` gives every move an element cast (bolt, pillar, vortex, fissure, nova, echo, cleave, avatar, crown, rift, wheel, tomahawk, guillotine) fired from `player._cast()`. Spirit casts are shaped spectral copies of the hero's own axes (`spirit_echo.ghost()`), not light flashes; after an Ascendancy each axe takes its element's form (`spirit_echo.FORMS`: earth dark molten with spikes off the edge and butt, water pale ice with icicles and a point, wind swept wing blades; the extra blades share the body's materials so they fade with it): echo = `scripts/spirit_echo.gd`, a giant spectral axe sweeping the swing's arc a beat later (L1, L2 wider); cleave = `scripts/spirit_cleave.gd` (L3), two colossal axes rise either side of the target and slam inward into a V (side-on to the top-down camera so they read; a straight-ahead chop is edge-on). avatar = `scripts/spirit_avatar.gd` (CH): a 3x spectral copy of the shaman (the Barbarian model with ghost materials, 2H axe) looms over his shoulder and plays the overhead chop, landing `LAND * scale_to` ahead (measured from the animation: impact at 53%); `slam_fx()` there is the shared floor-cracking impact. crown = `scripts/spirit_crown.gd` (LH): three colossal axes burst blade-up from the floor round the target's element column and launch it; every blade face is turned to the camera behind the hero. rift = `scripts/spirit_rift.gd` (LLH): a wave of axes bursting from the floor one after another along the thrust, growing and leaning into it (blades alternate sides; spirit/wind skip `spikes()` there, which are light columns that would hide them). wheel = `scripts/spirit_wheel.gd` (H 4 axes, DH 6): giant axes laid flat like a sawblade, whirling round the hero (child of him, so it follows the Cyclone dash), grinding everything in reach every `TICK`. tomahawk = `scripts/spirit_tomahawk.gd` (DL; LPL fans two smaller): a giant axe flung spinning flat, piercing out to `range` and boomeranging back to the hero (each foe hit once per leg). guillotine = `scripts/spirit_guillotine.gd` (LHH Spike): a colossal axe drops blade-first from the sky onto the target and buries itself (no launch: Spike drives foes down). Spirit casts swell with the chain: each `Fx.CHAIN_TIERS` tier adds `player.CAST_GROW` size/reach and `CAST_POWER` damage (`_cast_grow()`, `_cast_power()`; common setup in `player._spirit()`). Ultimates use them too: Ancestor's Fall summons a `SKY_ANCESTOR` (5x) avatar behind the target whose axe lands with the hero (`_sky_ancestor`, `spirit_avatar.speed_for()` times it; visual only), Spirit Stampede's wake raises a rift of huge axes down the charge line (`_rush_blades`, visual only). Cataclysm slams `CATACLYSM_AXES` colossal axes down in a ring round the hero and the Trinity drops one on every foe it strikes (`player._axe_fall()`: visual-only guillotines with `heavy = false`, a light `slam_fx` without hitstop so volleys don't stack it). Windowless check: `godot --headless --path . -s tests/cast_dump.gd -- --cast=cleave --t=0.5` then `python tools/render_hero.py <user://cast_dump.json> out.png front,top` (`--cast=echo|cleave|avatar|crown|rift|wheel|tomahawk|guillotine`, `--size=` overrides the scale, `--el=` the element, `--cast=cataclysm` the landed ring; flat decal quads are skipped; skinned meshes are skinned on the CPU, so the avatar shows its real pose); `LOOK` is each element's palette; also the orbiting motes and the ultimates' effects. `prewarm()` draws every material once at load (first-use shader hitches). `player.ULTIMATES` (SKY = Awakened L H H, RUSH = Awakened Dash L H, plus AF) run in `State.ULT`; each adds `ULT_CHAIN_BONUS`, all three in one Awakening fire `TRINITY`. HUD banner via `Game.ultimate`, camera push-in via `camera_rig.punch()`
- `scripts/hero_look.gd` — the shaman's look on the KayKit Barbarian: recoloured texture (`tools/gen_shaman_texture.gd` `RECOLOR`, per palette swatch), bear hood and pelt cape hidden (`player.HIDDEN_MESHES`; the cape becomes `ShamanMantle`: ragged cloth panels + feather fringe, recoloured per Ascendancy via `FORMS.cloth`) for a faceted mohawk + braid (`ShamanHair`) and headband with feathers, necklace on bones, axe runes; `coat_axes()` coats both axes in the current element (see-through shell + glowing gem + wind feathers / lava spikes / ice spikes + motes the blade sheds), swapped on `player.ascend()`; `charge_coats()` brightens them and triples the motes while Awakened. `set_eyes()` lights glowing eye slits (`AwakenEyes`, `EYE_POS`) in the Awakened colour. `scripts/ascend_aura.gd` = the Ascendancy's always-on aura (ground glyph + element motes; Tempest adds a low swirl), swells via `set_awakened()`. Ascendancy forms: `FORMS` / `add_form()` here (flat-shaded low-poly gear on bones: Tempest crest + feather mantles, Magma obsidian pauldrons/horns/lava crystals, Tide ice crown + shoulder shards), added by `player.ascend()`; its glowing pieces pulse (brighter while Awakened via `charge_form()`) and the Tempest crest sways (`_sway`). Close-up check: `godot --path . -s tests/hero_preview.gd` → `user://hero_preview.png`; windowless (no Godot window, rough flat render): `godot --headless --path . -s tests/hero_dump.gd [-- --ascend=earth --awakened]` then `python tools/render_hero.py [dump out views]` (views e.g. `front,3/4`: ~1 min per view) → `user://hero_render.png` (front, 3/4, side, back; skinned meshes in T-pose; includes aura meshes, not particles; decal textures draw as flat squares)
- `scripts/boss.gd` — Bone Warden boss (extends enemy.gd); attack tuning in its `ATTACKS` table, fought in the last room (`main.RUN_LENGTH`)
- `scripts/altar.gd` — bone altar: banked bones and permanent boons (`BOONS`, `user://altar.cfg`), bought from the title screen, applied in `main._apply_altar()`; disabled in the autotest
- `scripts/records.gd` — saved run records (`user://records.cfg`), shown on the title screen and flagged on the run summary
- `scripts/spike_trap.gd` — floor spike hazard used by `main.LAYOUTS`
- `scripts/projectile.gd` — enemy bolts; i-frames pass through, perfect dodge still triggers
- `assets/sfx/` — synthesized placeholder sounds; regenerate with `python tools/gen_sfx.py`, play with `Game.sfx("name")`
- `assets/music/` — synthesized ambient + combat loops; regenerate with `python tools/gen_music.py`. `Game` plays them in sync and fades the combat layer by style rank (`MUSIC_RANK_LEVEL`)
- `scripts/combo_guide.gd` — the combo guide beside the hero mid-string: reads `player.combo_options()` (rows built from `player.route()`, the one routing function `_next_move` also uses) and `combo_window()` every frame; toggle `Game.combo_guide` (Settings)
- `scripts/hud.gd` (+ `enemy_bars.gd` health bars, `threat_arrows.gd`), `scripts/camera_rig.gd`, `scripts/fx.gd` (damage numbers, sparks, rings, flash; textured sprites from `assets/vfx/` via `Fx.TEX`: `burst(..., tex, add)` particles, `flare()` camera-facing pops, `particle_mat()` shared by elements.gd; `swoosh()` = each melee hit's arc out to the move's `range`/`arc` (shaders/swoosh.gdshader, called from `player._swoosh()`, colour = the weapon trail's: element at rest, Ascendancy when Awakened). `weapon_trail.gd` + shaders/weapon_trail.gdshader = the ribbon on the axe. Kills: `death()` (gold flash + shock ring + `shards()` = shaded low-poly debris + smoke) from `enemy._die()`, `soul()` wisp as the corpse sinks. Combo feel: `chain_spark()` (from `enemy.take_hit`) adds hit flourishes in the hero's colour as `Game.combo_count` passes `Fx.CHAIN_TIERS` (10/20/35: star, spark spray, ring); `combo_pop()` bursts at the hero when a named combo lands (`player._combo_callout`), scaled by tier. Enders also get extra hitstop and a camera push-in per tier (`player.ENDER_HITSTOP`/`ENDER_ZOOM`, `_camera_hit`), and big hits/enders a directional nudge (`camera_rig.kick()`, scaled by the shake setting). Combo enders and chains past the 2nd tier add a second, wider, hotter swoosh (`player._swoosh`). Style rank climbs burst at the hero in the HUD's rank colour (`player._on_combo_changed`, camera push from S up). A fight's final kill gets slow motion + camera push-in + gold rings (`player._last_kill`, `LAST_KILL_SLOWMO`; autotest prints `[autotest] last_kill #N`). Every melee hit also throws debris off the element-coated axes (`Fx.element_hit()`: spirit wisps, wind streaks, obsidian chips + embers, ice shards + frost). `scorch()` = floor burn decal (flashes the colour, cools to soot): Cataclysm (`player._cataclysm`: fire vortex `_fire_vortex` = swirl funnels with gold streaks, shards, scorch) and fire waves (`fire_wave.gd`: flame-tongue flares + scorch trail). Dash: `dash_streak()` floor smear + afterimages in `player._fx_color()` (element, or Ascendancy when Awakened); perfect dodge adds a big blue flare, rings and sparks. Awakening activation: `awaken_burst()` (faceted light `beam()` + flash + double shockwave + motes) in `player.try_awaken()` with a camera punch. Wind pillars (casts, fissure, SKY/RUSH tornadoes) are `elements.funnel()` cones with `swirl_mat()` (shaders/swirl.gdshader: spiral bands; saturated body via from_hsv since darkening pale colours goes grey); the same shader (low twist) makes the water geyser jet and (tight spiral) the spirit beam's shell. Prewarm (`elements.prewarm`) must draw new effect materials at real size under its 5% root; sub-pixel draws may skip the compile. Additive only for small hot cores: big additive shapes wash out on the light floor; pale flares need saturation to read)
- `assets/kaykit/` — CC0 models (see CREDITS.md). `vendor_src/` holds the full packs; it's gitignored and `.gdignore`d — copy pieces into `assets/` to use them.

## Workflow
- Headless check (compile + 12s bot playthrough): `godot --headless --path . -- --autotest`
- Visual check (screenshots to `%APPDATA%/Godot/app_userdata/Awaken/autotest_*.png`): `godot --path . -- --autotest`
- Effect preview (isolated, game camera and lighting, screenshot to `user://fx_preview.png`): `godot --path . -s tests/fx_preview.gd [-- --at=0.06]` (`--at` = seconds after spawn; flares peak ~0.03–0.08s); `-- --swoosh` shows the melee arcs instead, `-- --death` the kill effects, `-- --dash` the dash and perfect dodge, `-- --awaken` the activation burst, `-- --shots` enemy projectiles (halo + trail) and their pop. Swing trail mid-swing: `godot --path . -s tests/trail_preview.gd` → `user://trail_preview.png`
- Autotest also saves `autotest_hit.png` ~0.2s after the first big hit, for checking impact VFX, and prints a `[perf]` line (avg/worst frame ms, spikes >25ms with timestamps, max enemies/draw calls); measure perf windowed, not headless
- Menu check (title + pause + settings + run map screenshots to `user://menu_*.png`): `godot --path . -s tests/menu_check.gd`
- Enemy lineup (one of each `ENEMY_TYPES` in a row, `user://enemy_lineup.png`): `godot --path . -s tests/enemy_lineup.gd`
- Telegraph check (melee windup at 25/50/75/95 %: rim fixed at full reach, fill grows to it via `enemy._scale_fill()`; `user://telegraph_preview.png`): `godot --path . -s tests/telegraph_preview.gd`
- Occlusion check (hero parked behind a pillar, `user://occlusion_check.png`): `godot --path . -s tests/occlusion_check.gd`
- After adding assets **or a new `class_name`**: `godot --headless --import --path .` (registers global classes)
- `-- --autotest --all-upgrades` starts with every upgrade to exercise all effects (`--max-upgrades`: all at max level; `--upgrades=quake,bone_breaker` for specific ones); `--start-room=N` skips ahead (8 = boss; add `--boss-enraged` for phase 2 → `autotest_spikes.png`; `--boss-attack=cage` forces one `ATTACKS` key → `autotest_cage.png`), `--twist=volatile` makes it an elite room with that twist (`--twist=volatile,hasted` for two; `--twist=splitting` → `autotest_split.png`), `--altar=hardened:3,scavenger:1` applies bone altar boons without saving, `--low-hp` starts at 15% HP (`autotest_lowhp.png`), `--reduce-flashing` turns that setting on without saving, `--start-rest` opens on a camp with 30 bones (`autotest_camp.png`), `--start-shrine` on a shrine with 30 bones (`autotest_shrine_room.png`, `autotest_shrine.png`; `--shrine-trade=vow|melt` forces and takes that rotating trade), `--start-vault=light` opens on a vault of that path (`autotest_vault_room.png`), `--start-trial=untouched|swift|stylish` on a trial (prints `[autotest] trial=... met|failed`), `--start-mystery` on an unknown room (prints what it was revealed as), `--start-awakened` starts with a full meter (bot lands Cataclysm → `autotest_finisher.png`). The first synergy saves `autotest_synergy.png`; the first Ground Breaker saves `autotest_breaker.png` (+ `autotest_fault.png` with Fault Line) and the first charged slam `autotest_slam.png`, the first Shatter `autotest_shatter.png`. Autotest also saves `autotest_summary.png`
- `--seed=N` repeats a run's doors, twists, spawn order and reward offers (`main.run_rng`; combat itself still varies with timing); the autotest line prints `seed=`; `--daily` seeds from today's date like the title's "Daily run" (`main.daily_seed()`)
- Elements: `godot --path . -s tests/element_preview.gd` renders every cast and ultimate impact per element (`user://element_*.png`, 2x2 sheets `element_sheet.png` / `element_ult_sheet.png`; `-- --only=earth` for one); `godot --headless --path . -s tests/ult_check.gd` checks casts, ultimate routing/damage/chain and the Trinity for every element (PASS/FAIL). Autotest prints `casts= ults= chain= impacts= trinity=` and saves `autotest_cast.png` / `autotest_ult.png` / `autotest_trinity.png` (with `--start-awakened` the bot lands all three ultimates and the Trinity)
- Move hops (`MOVES` `hop` = [start, end, height], `player._hop()`): L3 leaps onto its hit, LH rises with the launch, LHH drops from that height onto its hit (a move started in the air lands by its first hit), CH leaps into the slam; only the model lifts. Check: `godot --headless --path . -s tests/hop_check.gd` (PASS/FAIL)
- Combo breakers (`player.BREAKERS`, see `docs/features/combo-breakers.md`): timed aerial finishers. LLH leaps up and back mid-move (`State.LEAP`, `_state_leap`), hurls spectral axes (`scripts/breaker_spike.gd`: ghost copies of his axe in the element's form, spinning in and burying head-first) onto a zone ahead and rings it with a timing cue (`scripts/breaker_cue.gd`: closing ring meets the target ring at `sweet`); heavy in `open..close` dives onto the zone (detonating the spikes, each foe once; within `perfect` of `sweet` = PERFECT x`perfect_mult`), too early locks it out, no press floats him down. hold H (Charged Slam) leaps forward after the launched foes instead and juggles them inside a spectral sawblade (`juggle` keys: `_juggle()`, a `spirit_wheel` on the model) before the same timed slam. Flurry (LPL) stays grounded: hop back into a stance, and the press dashes through the line (`dash` keys: `_dash_cut()`, then `_dash_wake()` raises a spirit_rift along it). The window plays in slow motion (`BREAKER_FOCUS`, camera push-in), and a press ends it (`Game.end_slowmo()`); a perfect press freezes the frame for `BREAKER_PERFECT_STOP` first. Awakened, the dive breakers summon a `BREAKER_ANCESTOR` (4x) ancestor as the window opens, timed to chop down with the dive (`_breaker_ancestor`, visual), and Flurry's wake grows `BREAKER_AWAKENED_WAKE`. Cyclone (DH) spins up on the spot in a sawblade that pulls foes in (`pull`), and the press flings a ring of `fan` tomahawks (`_fan_release`, one shared hit record per leg via `spirit_tomahawk.shared`). Mid-leap the combo guide shows one heavy row with the breaker's name (`_breaker_options()`, `breaker_name()`), ready inside the window. The bot presses at `sweet` and prints `[autotest] combo_breaker #N <id> perfect=`. Check: `godot --headless --path . -s tests/breaker_check.gd` (perfect/late/early/none/awakened per breaker, PASS/FAIL); look: `tests/cast_dump.gd -- --cast=breaker --t=0.45 [--breaker=CH|LPL|DH]` (`--t=-0.4` = after a perfect landing)
- Combo guide: `godot --path . -s tests/guide_check.gd` checks every guide row and follow-up against the real routing (PASS/FAIL, headless works) and renders six states to `user://guide_sheet.png`; autotest prints `guide=` and saves `autotest_guide.png`
- Levels/Ascendancy: `--level=N` starts at hero level N (6 opens the Ascendancy choice at the first clear → `autotest_ascend.png`), `--ascend=wind|earth|water` starts ascended; `godot --headless --path . -s tests/ascend_check.gd` checks every element effect (PASS/FAIL)
- Room pacing (`-- --autotest --pace`, with `--start-room=N` / `--twist=X` / `--seed=N`): ends at the first room clear and prints `[autotest] cleared room=N kind=... time=`
- Room tour (`-- --autotest --tour`): forced doors fight → rest → shrine → elite → boss, fights wiped after 1.5s; camp buys its first offer and the shrine takes its rotating trade; prints `[tour] PASS/FAIL rooms=... trades=...` (~16s, works headless)
- Wiki (`docs/wiki/index.html`, open from disk): `python tools/wiki.py` regenerates `data.js` from the tuning tables (`tools/wiki_data.gd`) and flags ids missing from the hand-written `notes.js`; `--shots` re-captures `img/` (~4 min). Skills in `.claude/skills/`: `update-wiki` (refresh it), `roadmap-item` (one change end to end: build, verify, ROADMAP, commit)
- **Engine API reference:** `docs/engine_api/<ClassName>.xml` is the class reference for the exact Godot in use (`VERSION`; also `@GDScript.xml`, `@GlobalScope.xml`). Before using an engine method, property, signal or enum you aren't certain of in 4.7, grep it there (e.g. `method name="look_at"` in `Node3D.xml`, or search all files for a name) rather than recalling it. Regenerate after upgrading Godot: `python tools/gen_engine_api.py`
- **Feature docs:** `docs/features/` has a technical write-up per feature (how it works, files, invariants, tuning, tests); see its README for the index and the template. Read the relevant one before changing a feature, and add or update one in the same commit when you build or change a feature
- Scenes are mostly built in code; keep `.tscn` files minimal unless the user wants editor-authored scenes.
- KayKit models face +Z; facing yaw = `atan2(dir.x, dir.z)`. Characters share one rig, so any KayKit animation works on any character.
