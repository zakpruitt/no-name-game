Simple kits

The heretic starts every run as the dark alone: eight slots, three presses at most. The run gives him back his storm, ice and magma, one element at a time, and the moves he has today become what a run can earn.

  • The base kit is the tentacle. The light string, Reap, Singularity, Overwhelm, Dash Stab, Tow Line, the counter and the Awakening. Eight slots. No input is longer than three presses. Three breaker windows, each with one ending.
  • With no element yet, H after the string is the grab. The code already does this when a move is gated. So L H H is Slice, grab, Singularity. The string feeds the tentacle until a run gives it a colour.
  • An Attunement is taking one element for this run. It recolours its weapon and lights that element's ender and its big move, with the H ending. A run holds two of the three.
  • Techniques are the rest of today's kit, as picks. The six crossovers, Black Tide, the air route, Deep Freeze, Storm Pitch and the eight second endings on breakers. A crossover is offered once you hold both its elements, and it is always in the next Technique offer. A run takes about 5 (run.html's number), three of them its crossovers.
  • Nothing is deleted. All of it is already behind Kit.has() or can be, through data in kit_slots.gd. The end of a run is about 16 slots, not 24, and it is a different 16 each time. The 18 richer element cells are Boons, on loot.html.
  • What it buys: the part every minute of every run touches drops to 8 slots, 3 windows and 3 endings. That is the polish target. Everything else can wait its turn.

The verdict, slot by slot

The heretic's card in kit_slots.gd has 24 slots in 10 groups. Each one gets one of five verdicts:

  • Base: in the starting kit of every run.
  • Attunement: lit when the run takes its element.
  • Crossover: a Technique whose prerequisite is holding both its elements. Once that is met, it is always in the next Technique offer. Dark is always held, so each dark crossover is offered right after the Attunement of its colour.
  • Technique: a pick during the run, with a prerequisite.
  • Merged or parked: stays in the code behind its gate, not offered in runs for now.

The hard parts, dealt with

The light string and its enders, with no Attunement

Today the string swings the axe (storm), then the spear (ice), then the hammer (magma). The tint is only a colour: the plain hits Slice, Hurl and Triple Chop set no state. Only the enders do. So the string itself does not need to change.

The ender is the real question. Each H off the string belongs to one element. With that element not held, void_route() already falls back: when KitSlots.open() says no, the press plays NEUTRAL, the grab. So with no Attunement:

  • L H, L L H and L L L H are the string, then the grab. The grab reaches 9 m all round.
  • One more H is Singularity, and the window is Collapse. One more L is Reap.
  • The rule a new player learns is short: L is the weapon, H is the tentacle. Taking storm later changes what L H does, and the player sees it change.

The tint has three options:

A. Keep the colours

Axe green, spear cyan, hammer orange from room one. Cost: none. The colours promise elements the player does not hold yet.

B. Weapons form in the void until attuned

An un-attuned weapon grows from the arm in its magenta and violet-black. Taking storm turns the axe green for the rest of the run. Cost: a palette switch per weapon form, plus Zak's eye on three recolours. It makes the Attunement something the player sees on every swing (spine rule 4). Build it after the gate works with option A.

C. One weapon until attuned

The string is three tentacle lashes. Cost: new clips and new pacing for the most-played input in the game. Rejected.

Route steps

The grab (H), Air Slash (L H L), Rockslide (L H L L), Ice Cube (Dash L H H) and the vault (L L H L) are not slots and never Techniques. They come with whatever route needs them. The grab is base. Air Slash comes with storm. Rockslide's buried payoff stays with Fault Line, which needs it. Ice Cube comes with Harpoon.

One needs care: the vault is not routed through void_route() but through VOID_ELEMENT.vaults(). With Deep Freeze not taken, the vault would still fire off Frost Spear and lead nowhere. It needs one more condition there (a few lines, new behaviour).

The 15 breaker windows

A new player meets three, one at a time, each with one ending on H:

  1. Collapse (H H, then H) in the first room. This is where the window is taught.
  2. Abyss (hold H, then H) at the first big foe.
  3. Ricochet (a perfect counter, then H) at the first foe that swings.

Second endings on breakers

Nine windows have two endings today. In the base kit every window has one, the H. Every L ending becomes a Technique: Short Circuit, Cold Front, Meteor Shower, Black Ice, Uproot, Tempest, Pinwheel, Slapshot (Backdraft's Pinwheel is parked with it). The rule for their prerequisite is simple: an L ending in a third colour needs that colour held. Cold Front is ice on a storm window, so it needs ice. Uproot is dark on a dark window, so it needs only Overwhelm.

Today L in a window with no alt does nothing (hero_leap.gd only reads L when the row has one). So gating an ending is two checks there plus a Kit id per ending. Small new behaviour, and the window then plays exactly like Collapse does today.

The counter

Base, as it is. The risk is teaching it too early: it needs a foe that swings, and the training dummies do not. The first room should hold one striking foe, near the end (that is run.html's call). The Gallows flourish on Ricochet bends a room rule, so it belongs with Boons on loot.html, not here.

The Awakening

Base. It adds no inputs, and the three base windows fill its meter, so it rewards the thing the base kit teaches. Do not mention it until the meter is full the first time. One note for run slice 3: Awakening charges the axe's element today; check that it reads right on a void axe.

The swing round a pillar

R and Snatch (R, then H) are not slots. They are room verbs. They stay as they are and are taught where the first pillar is, not in the first minute.

What the first room teaches

  1. L is the weapon. L L L on a group of minions.
  2. H is the tentacle. H grabs everything near. H H pulls them together.

What the player can hold in their head

"Light is the weapon. Heavy is the tentacle. Heavy twice is the gather. Hold heavy for the big one. Dash, then either button. Dash into a hit to counter. Press heavy when you leap."

Seven sentences. Compare today: 24 slots, 15 windows, 24 endings, inputs up to six presses.

Attunements

An Attunement is taking one element for this run. It is the biggest single reward a run gives, and it changes the character in a way the player sees on the next swing.

What one Attunement gives

The same three things for every element:

  1. The tint. Its weapon in the string takes its colour (option B above).
  2. The ender. The H off its string position stops being the grab and becomes the element's move. It leaves the element's state.
  3. The big move. One move with one window, H ending only. Where the grammar allows, it is the ender plus one more H, so the player learns the two as one idea.

The crossovers do not come with it. Each is a Technique whose prerequisite is holding both its elements, and once that is met it is always in the next Technique offer (run.html). Dark is always held, so the element's dark crossover is offered in the very next Technique pick. The kit still grows one idea at a time.

Two honest gaps. Magma barely leaves molten today. Its core moves leave bound and wall-splat; molten comes from Lava Leash, Hellseam, Meteor Shower, Meltdown and Eruption, and none of those is in the magma Attunement. Recommend Molten Palm's seam leave molten for 2 s on the foes it carries (small new behaviour), so the magma Attunement feeds its own rule. Ice's big move breaks the pattern. Storm's big move is the ender plus H, and so is magma's. Ice's is not quite, either way: Deep Freeze puts the vault step between the ender and the H (L L H L H, five presses), and Harpoon is off the dash. See the choice below.

Ice: Harpoon or Deep Freeze

A. Harpoon is ice's big move

Three presses, works anywhere, freezes up to five into a row, and Shatterstorm is reliable. It is also where Steam Burst and Hailstorm start, so the ice crossovers need it. Deep Freeze becomes an ice Technique called "the vault". Cost: data, plus the vault gate.

B. Deep Freeze is ice's big move

Matches the grammar (ender, then H). But it is five presses, needs the spear standing and a vault, and Harpoon becomes a Technique that two crossovers depend on. The ice Attunement would feel the hardest to use of the three.

How many a run can hold

One

Simplest. Only three kinds of run, and only the three dark crossovers are ever seen. Fault Line, Steam Burst and Hailstorm never play. Too little change between runs.

Two

Three pairs, and order matters for the early rooms. Each run sees three crossovers: two dark ones and the pair's. Every run is missing one colour, which is what makes runs feel different. The end kit stays near 16 slots.

Up to three

The third late. Every full run ends as today's heretic, so runs converge and the end of a run is the 24-slot kit this page exists to avoid. Keep it as a "Not yet".

When and how often an Attunement is offered is run.html's cadence. This page asks for one thing: the first Attunement should come soon after the first room, because the base kit has no colour and the colours are the fun.

Crossovers exist only while both are held

Each crossover slot already names its pair in KitSlots.SLOTS ("pair": ["wind", "earth"]). The gate reads it: a crossover can be offered only when both elements are held. Dark always is. Each crossover is a Technique: once its pair is held, it is always in the next Technique offer, so the player meets it one room later, as one new thing to press.

This page first proposed giving the crossovers free with the Attunement, all at once. The hub rules the other way, so the kit grows one idea per room; the free version is kept as the alternative in the hub's decisions.

Why these read as three characters

  • The weapons differ: in the squall the hammer stays void all run; in the kiln it is the axe.
  • L H is a launcher in two runs and the grab in the third.
  • Dash L H freezes a row in two runs and is Dash Stab then the grab in the third.
  • Each run has a state the others do not: charged and frozen, frozen and molten, charged and buried.

Techniques

A Technique is one demoted piece of today's kit, offered back as a pick. It always adds something you press: a new input, or a new ending in a breaker window. Each one has a prerequisite: a slot it hangs off, and sometimes an element held.

Two kinds. New inputs add a press to the kit (the crossovers, Black Tide, the air route, Deep Freeze, Storm Pitch). Second endings add an L press in a window the player already has. Most of the non-crossover pool is second endings on purpose. They make a run different without making it harder to hold.

Element cells are Boons, not Techniques

The matrix collapse (round 49) left one rule per state and moved 18 richer cells behind IMPROV_UPGRADE. Off, the rule plays. On, the cell plays instead. A cell adds no press: it changes what a state pays. So the cells are Boons, and they are loot.html's first boon pool (Shard Cut, Gale Lift, Overload, Superconduct and the rest). This page does not offer them.

The simple-kit template

The rules a future character must fit. Written so an agent can design character two from this section alone.

Rules

  1. One signature, three elements. Unchanged from the grammar. The signature's state is marked / bound. Each element maps to one of the six states; no new states.
  2. The full card is the grammar's 24 slots. It is the ceiling and the map. No character has more.
  3. The base kit is exactly 8 slots: the light string; three signature verbs (mark, gather, pin); Dash L; Dash H; the counter; the Awakening. The fourth signature verb (drag) is a Technique.
  4. Base inputs: 3 presses at most, a hold counts as one. The string's H with no element is the signature's neutral H.
  5. Base windows: 3 (gather, pin, counter), one ending each, the H.
  6. Each element is an Attunement of the same size: its string tint, its ender, and one big move with one window (H ending only). Big move: 5 presses at most, ender then H where possible, so the two are learned as one idea.
  7. A run holds 2 Attunements.
  8. Six crossovers, one per colour pair: three signature x element, three element x element. Each 5 presses at most. Each is a Technique, offered once both its elements are held and always in the next offer. At least 4 of the 6 have a window.
  9. Technique pool: 10 to 14 cards per character, plus the six crossovers. 3 to 4 new inputs (the drag, the air route, a second big move per element where one exists) and up to one second ending per window (only where both endings have a clear best situation). The element cells are Boons (loot.html).
  10. Every Technique states its prerequisite as a slot plus elements. An L ending in a third colour needs that colour.
  11. Every Technique changes what the player does or sees. No Technique is only a number. Numbers are for Gear (loot.html).
  12. Route steps are never Techniques and come with whatever route reaches through them.
  13. Input caps across the run: base 3, Attunement and crossover 5, Technique 5. A 6-press input is parked.

What the pruning buys

  • A third of the surface is the whole first impression. 8 of 24 slots, 3 of 15 windows, 3 of 24 endings.
  • Feedback lands where it counts. A rough edge in Hailstorm is seen in one run in three. A rough edge in Singularity is seen every minute.
  • The run has something to give. The 16 slots and 21 endings outside the base are the rewards, and they are already built.
  • Character two costs less. Its first playable is 8 slots, not 24.

What it does not buy

  • It does not remove code. The gated moves still need their autotest strings to stay green, with --kit=full.
  • It adds a little new judging: the void weapons, the Attunement moment, and the L press in windows that lost their second ending.

One thing to watch: Kit is static, global state. That suits a run (set on pickup, clear at run end), but a run must clear it, or the next run starts with the last one's kit.

Build order

The master order is run.html's ten slices. These steps are the kit's detail inside two of them: run slice 2 (the small kit and Techniques) and run slice 3 (Attunements). Each is also playable in the training room with a flag, so it can be judged before the run's rooms exist.

The base kit alone

Base, Attunement and Technique data in kit_slots.gd; open() honours it; --kit=base. Play the training room and the spar foes with eight slots. Judge: is five minutes of the dark alone fun? Does L L L H H (string, grab, Singularity, Collapse) feel like one combo?

Techniques

The second-ending gate and the vault gate. --tech=black_tide,slapshot to turn cards on; run slice 2's offers call Kit.set_on() on the same ids. Judge: does each of the 12 change what you do? Cut any that does not.

One Attunement

--attune=wind lights storm: Updraft Lash and Live Wire. Galvanize comes as the next Technique offer. Judge: does taking storm feel like a change? Is L H turning into Updraft Lash a good surprise or a confusing one?

Pairs

All three Attunements and the pair gate on crossover offers, Impale absorbing Backdraft, Meltdown parked. Play the three pairs. Judge: do the squall, the kiln and the quake feel like three characters? Is storm and ice too thin?

See it

Void weapons until attuned. Molten Palm leaves molten. Judge: can a viewer tell which run it is from a screenshot?

Decisions for Zak

Does every run start with no element, the dark alone? Yes. The elements are the run's biggest reward, and the base kit is then truly simple.
Is the base kit the string, Reap, Singularity, Overwhelm, Dash Stab, Tow Line, the counter and the Awakening? Yes. Black Tide is the one tentacle verb that goes to Techniques.
With no element, is H after the string the grab? Yes. It is what the code already does, and it teaches "H is the tentacle".
Ice's big move in a run: Harpoon or Deep Freeze? Harpoon. Deep Freeze becomes a Technique.
How many Attunements can a run hold? Two.
Is a crossover a Technique, always in the next offer once both its elements are held? Yes (the hub's ruling). The alternative, this page's first draft, gives every crossover free with the Attunement.
Does Impale become the dark-ice crossover and absorb Backdraft? Yes. Same window, same endings, one press shorter.
Are Meltdown and Eruption parked while a run holds two elements? Yes, unless the storm-and-ice runs feel thin; then Meltdown returns for that pair only.
Do the 18 element cells go to Boons on loot.html? Yes (the hub's ruling). They add no press; they change what a state pays.
Un-attuned weapons drawn in the void's colours? Yes, in run slice 3, after the gate is judged with today's colours.
About five Techniques per run, three of them the crossovers? Yes, run.html's number, as a starting target to tune.
Should Molten Palm leave molten? Yes, briefly, so magma feeds its own rule.

Risks

The first room may feel grey. The colours and the state payoffs are the heretic's joy, and the base kit has none of them. If run slice 2 shows room 1 is dull, the fix is a fast first Attunement (run.html), not a bigger base kit.
The string-to-grab flow is untested as a combo. Triple Chop's knockback may push foes out of the grab's moment, or the grab may feel like a dead press after the hammer. Run slice 2 finds out.
The same input changes meaning between runs. L H launches in one run and grabs in another. That is the point, but muscle memory from the last run will misfire for a room. The weapon tint is the main defence.
Storm and ice is the weakest pair. Its own crossover has no window. Watch it in run slice 3.
Moves were tuned assuming the full kit. Harpoon's pause, Impale's pause and the vault rules were shaped around neighbours that may not be there. Expect small retiming.
The test harness doubles. kit_check and the autotest now check a full card. They must also check the base kit, each Attunement and each pair, or a gate will quietly break a route.
This repeats an old shape. The earlier game had an Ascendancy (pick Wind, Earth or Water) and two-colour fusion cards. The difference: those were numbers on top of a thin combat; these are moves already built and polished. Keep it that way: no Technique that is only a number.

Not yet

A third Attunement. It makes runs converge on today's kit. Revisit only if two-element runs feel small after many plays.
Technique levels. No card upgrades itself with numbers. Numbers are Gear's.
New moves. The pool is today's kit. Do not invent a Technique until the 12 have been judged in runs.
A run-mode MOVES panel. Today's panel shows gated rows dim. That may be fine; a panel that hides unlit groups is only worth building if dim rows confuse.
Character two. The template is ready, but the heretic's runs come first.
Room flourishes as run rewards (Gallows, Ice Rink, Brazier Spill). They are Boons, and wait on loot.html's Not yet until the run's rooms carry their pieces.
